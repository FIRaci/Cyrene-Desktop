                    Voice Cloning (Mossland Permanent Lib)
                  
    
                  
                
    
                
    Upload reference audio (wav/mp3/m4a, ≤60s), Mossland will create a permanent voice_id.
    
                
    
                  Mossland voices are permanent, no '7-day expiry'. The voice_id is returned by Mossland backend, fill it in 'Voice ID' above to reuse.

Mossland uses multipart clone upload, returns permanent voice_id.
